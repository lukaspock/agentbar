# Claude Code hook E2E (AgentBar ClaudeCodeAdapter)

Run 2026-11-01 with Claude Code 2.1.283. `~/.claude` was never touched.

## Setup used
- `swift test` target `ClaudeCodeEndToEndTests` (Packages/AgentBarCore/Tests/AgentBarCoreTests): real `TransportServer` + real `ClaudeCodeAdapter` (wrapped in a payload-logging adapter) + real `agentbar hook` child process.
- Real run (opt-in, `AB_REAL_CLAUDE=<allow|deny|always|timeout> AB_REAL_OUT=<dir>`): settings file generated by `HookSetup.planInstall()/apply()` into a temp file, then
  `claude -p "<Write hello.txt>" --settings <tmp>/settings.json --setting-sources project --tools Write --permission-mode default --model haiku --max-budget-usd 0.5 --no-session-persistence` with cwd = temp dir and `AGENTBAR_DIR` pointing to the test server.
- The socket directory lives in `/tmp/abe2e-*` (the scratchpad path exceeds the 104-byte `sun_path` limit); removed in tearDown.

## Result of the real run (1 of 3 allowed runs used)
`claude -p` exited 1 with `Failed to authenticate: OAuth session expired and could not be refreshed` (reproduced with a plain `claude -p "reply with: ok"` outside the harness, so it is the local login, not the harness). No model turn happened, so **PermissionRequest, PreToolUse, Notification and Stop were NOT reached in a real run**; allow/deny/timeout-fallthrough against real Claude Code is therefore unverified. I did not attempt to log in (not permitted) and did not burn the remaining runs.

What the run did prove for real:
- `--settings <file>` with a HookSetup-generated config is accepted and hooks fire; with `--setting-sources project` none of the user's own hooks ran (only ours appear below).
- Real payloads for SessionStart, UserPromptSubmit, SessionEnd reached the adapter and were translated without error (the hook process returned empty output, exit 0).

## What is verified instead (fixture-driven, in `swift test`)
Realistic PermissionRequest fixtures (per the docs) through server + adapter + real `agentbar hook` process:
- allow -> stdout `{"hookSpecificOutput":{"decision":{"behavior":"allow"},"hookEventName":"PermissionRequest"}}`
- deny -> behavior deny + message; always -> allow + `updatedPermissions:[<suggestion localSettings>]`
- timeout/cancel -> empty stdout, exit 0 (never auto-allow)
- PreToolUse / SessionEnd -> empty stdout, store updated (working "Bash: npm test", ended).
